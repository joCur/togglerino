# Flag Lock Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow locking a flag's config in a specific environment to prevent accidental changes, with lock/unlock API, bulk operations, enforcement on all mutation paths, schedule checker integration, and dashboard UI.

**Architecture:** Add `locked`, `locked_by`, `locked_at`, `lock_reason` columns to `flag_environment_configs`. Lock/unlock via new API endpoints gated by `project:settings` permission. All config mutation handlers check lock status before proceeding (409 Conflict). Schedule checker skips locked flags. Frontend shows lock state with admin lock/unlock controls.

**Tech Stack:** Go 1.25 (stdlib net/http, pgx/v5, log/slog), PostgreSQL 16, React 19 + TypeScript + TanStack Query + shadcn/ui + Tailwind CSS v4

**Spec:** `docs/superpowers/specs/2026-03-11-flag-lock-design.md`

## Review Corrections (Apply During Implementation)

The following corrections were identified during plan review and MUST be applied when implementing:

### Go Test Corrections

1. **`FlagStore.Create` signature requires 12 args** — All test calls use 9 args but the actual signature is:
   ```go
   fs.Create(ctx, project.ID, key, name, description, model.ValueTypeBoolean, model.FlagTypeRelease, json.RawMessage(`false`), []string{}, nil, nil, nil)
   ```
   Use typed constants `model.ValueTypeBoolean` / `model.FlagTypeRelease`, not raw strings. Pass `json.RawMessage(`false`)` for defaultValue, `[]string{}` for tags, and three `nil`s for `envEnabled`, `ownerID`, `envOverrides`.

2. **Environments are NOT auto-created with projects** — Every test that does `es.ListByProject(ctx, project.ID)` will get an empty slice. Instead, explicitly create environments:
   ```go
   env, err := es.Create(ctx, project.ID, "development", "Development")
   ```

3. **Handler tests need `uniqueKey` helper** — The `internal/handler/` test package does not have `uniqueKey`. Add it or use inline `fmt.Sprintf("test-%d", time.Now().UnixNano())`.

4. **Use `model.RoleAdmin`** not `"admin"` — Follow codebase convention for user creation: `us.Create(ctx, email, "hash", model.RoleAdmin)`.

5. **Initialize error slices** — Use `errors := make([]string, 0)` not `var errors []string` so JSON serializes as `[]` not `null`.

6. **Evaluation cache queries use their own scan** — `internal/evaluation/cache.go` selects specific columns with its own scanner. It does NOT use the shared scanners and does NOT need lock columns added.

### Handler Corrections

7. **Bulk enable/disable lock enforcement should report errors** not silently skip. Return error message per locked flag in the results array, matching the existing bulk action error pattern.

8. **Promote lock check placement** — Add after sort order validation (line ~1094), not before, so invalid promotion direction returns 400 before we check lock status.

### Schedule Checker Corrections

9. **Mark schedule as `failed` not just skip** — Add a `FailSchedule(ctx, id, reason)` method to `ScheduleStore` (and the checker's `ScheduleStore` interface). Call it before returning so the schedule doesn't retry infinitely. Use status `"failed"` per spec, not `"skipped"`.

    Also update any existing `checker_test.go` that constructs `NewChecker`.

### Frontend Corrections

11. **TypeScript types are in `web/src/api/types.ts`** not `web/src/types.ts`.

12. **API methods should use `request<>()` directly** not `api.post`/`api.delete`:

16. **FlagHistory `formatAction` already handles lock/unlock generically** — No switch statement needed; the generic `action.replace(/_/g, ' ').replace(/\b\w/g, c => c.toUpperCase())` already works.

```go
func (h *FlagHandler) LockEnvironmentConfig(w http.ResponseWriter, r *http.Request) {
	projectKey := r.PathValue("key")
	flagKey := r.PathValue("flag")
	envKey := r.PathValue("env")
	if projectKey == "" || flagKey == "" || envKey == "" {
		writeError(w, http.StatusBadRequest, "missing required path parameters")
		return
	}

	project, err := h.projects.FindByKey(r.Context(), projectKey)
	if err != nil {
		writeError(w, http.StatusNotFound, "project not found")
		return
	}

	flag, err := h.flags.FindByKey(r.Context(), project.ID, flagKey)
	if err != nil {
		writeError(w, http.StatusNotFound, "flag not found")
		return
	}

	env, err := h.environments.FindByKey(r.Context(), project.ID, envKey)
	if err != nil {
		writeError(w, http.StatusNotFound, "environment not found")
		return
	}

	var req struct {
		Reason *string `json:"reason"`
	}
	if r.Body != nil {
		if err := readJSON(r, &req); err != nil {
			writeError(w, http.StatusBadRequest, "invalid request body")
			return
		}
	}

	if req.Reason != nil && len(*req.Reason) > 255 {
		writeError(w, http.StatusBadRequest, "lock reason must be 255 characters or fewer")
		return
	}

	// Check if already locked
	existing, err := h.flags.GetEnvironmentConfig(r.Context(), flag.ID, env.ID)
	if err != nil {
		writeError(w, http.StatusInternalServerError, "failed to get environment config")
		return
	}
	if existing.Locked {
		writeError(w, http.StatusConflict, "flag is already locked in this environment")
		return
	}

	user := auth.UserFromContext(r.Context())

		writeError(w, http.StatusUnauthorized, "unauthorized")
		return
	}

	cfg, err := h.flags.LockEnvironmentConfig(r.Context(), flag.ID, env.ID, user.ID, req.Reason)

		return

	// Best-effort audit log
	newVal, _ := json.Marshal(cfg)
```

```go
func (h *FlagHandler) BulkLockFlags(w http.ResponseWriter, r *http.Request) {
	projectKey := r.PathValue("key")
	if projectKey == "" {
		writeError(w, http.StatusBadRequest, "missing project key")
		return
	}

	project, err := h.projects.FindByKey(r.Context(), projectKey)
	if err != nil {
		writeError(w, http.StatusNotFound, "project not found")
		return
	}

	var req struct {
		FlagKeys       []string `json:"flag_keys"`
		EnvironmentKey string   `json:"environment_key"`
		Reason         *string  `json:"reason"`
	}
	if err := readJSON(r, &req); err != nil {
		writeError(w, http.StatusBadRequest, "invalid request body")
		return
	}
	if len(req.FlagKeys) == 0 {
		writeError(w, http.StatusBadRequest, "flag_keys is required")
		return
	}
	if req.EnvironmentKey == "" {
		writeError(w, http.StatusBadRequest, "environment_key is required")
		return
	}
	if req.Reason != nil && len(*req.Reason) > 255 {
		writeError(w, http.StatusBadRequest, "lock reason must be 255 characters or fewer")
		return
	}

	env, err := h.environments.FindByKey(r.Context(), project.ID, req.EnvironmentKey)
	if err != nil {
		writeError(w, http.StatusNotFound, "environment not found")
		return
	}

	user := auth.UserFromContext(r.Context())
	if user == nil {
		writeError(w, http.StatusUnauthorized, "unauthorized")
		return
	}

	var locked, alreadyLocked int
	var errors []string
	for _, flagKey := range req.FlagKeys {
		flag, err := h.flags.FindByKey(r.Context(), project.ID, flagKey)
		if err != nil {
			errors = append(errors, flagKey+": not found")
			continue
		}
		cfg, err := h.flags.GetEnvironmentConfig(r.Context(), flag.ID, env.ID)
		if err != nil {
			errors = append(errors, flagKey+": config not found")
			continue
		}
		if cfg.Locked {
			alreadyLocked++
			continue
		}
		_, err = h.flags.LockEnvironmentConfig(r.Context(), flag.ID, env.ID, user.ID, req.Reason)
		if err != nil {
			errors = append(errors, flagKey+": "+err.Error())
			continue
		}
		locked++

		// Best-effort audit per flag
		if err := h.audit.Record(r.Context(), model.AuditEntry{
			ProjectID:     &project.ID,
			UserID:        &user.ID,
			UserEmail:     &user.Email,
			EnvironmentID: &env.ID,
			Action:        "lock",
			EntityType:    "flag_config",
			EntityID:      flagKey,
		}); err != nil {
			slog.Warn("failed to record audit log", "error", err)
		}
	}

	writeJSON(w, http.StatusOK, map[string]any{
		"locked":         locked,
		"already_locked": alreadyLocked,
		"errors":         errors,
	})
}
```
