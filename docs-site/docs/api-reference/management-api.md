# Management API

All management API endpoints require session authentication (cookie-based) unless marked as **public**. Endpoints that require specific permissions are noted with the required permission.

All errors return JSON in the format `{"error": "message"}`.

## Authentication

### Check Setup Status

```
GET /api/v1/auth/status
```

**Public** - no authentication required.

Returns whether initial setup is needed and if OIDC is configured.

**Response** (200):

```json
{
  "setup_required": false,
  "oidc_enabled": true
}
```

### Create First Admin

```
POST /api/v1/auth/setup
```

**Public** - rate-limited. Creates the first admin user. Returns 409 if any users already exist.

**Request:**

```json
{
  "email": "admin@example.com",
  "password": "secure-password"
}
```

**Response** (201): User object. Sets `session_id` cookie.

### Login

```
POST /api/v1/auth/login
```

**Public** - rate-limited.

**Request:**

```json
{
  "email": "admin@example.com",
  "password": "your-password"
}
```

**Response** (200): User object. Sets `session_id` cookie.

### Logout

```
POST /api/v1/auth/logout
```

Clears the session cookie and deletes the server-side session.

**Response** (200):

```json
{
  "status": "logged out"
}
```

### Get Current User

```
GET /api/v1/auth/me
```

Returns the authenticated user's profile and org-level permissions.

**Response** (200):

```json
{
  "id": "uuid",
  "email": "admin@example.com",
  "display_name": "Alice",
  "role": "admin",
  "created_at": "2025-01-01T00:00:00Z",
  "updated_at": "2025-01-01T00:00:00Z",
  "permissions": [
    "org:users:manage",
    "org:oidc:manage",
    "org:projects:create",
    "org:projects:delete"
  ]
}
```

### Update Profile

```
PUT /api/v1/auth/me
```

Update the current user's display name or email. At least one field must be provided.

**Request:**

```json
{
  "display_name": "Alice Smith",
  "email": "newemail@example.com"
}
```

**Response** (200): Updated user object.

| Status | Description |
|--------|-------------|
| 400    | No fields provided or invalid email format |
| 409    | Email already in use |

### Change Password

```
POST /api/v1/auth/change-password
```

Rate-limited. Changes the current user's password.

**Request:**

```json
{
  "current_password": "old-password",
  "new_password": "new-password-min-8-chars"
}
```

**Response** (204): No content.

| Status | Description |
|--------|-------------|
| 400    | Current password incorrect, or new password less than 8 characters |

### Accept Invite

```
POST /api/v1/auth/accept-invite
```

**Public** - rate-limited. Creates a new user account from an invite token.

**Request:**

```json
{
  "token": "hex-encoded-invite-token",
  "password": "new-password-min-8-chars"
}
```

**Response** (201):

```json
{
  "email": "invited@example.com"
}
```

| Status | Description |
|--------|-------------|
| 404    | Invite not found |
| 409    | Invite already accepted |
| 410    | Invite has expired |

### Reset Password

```
POST /api/v1/auth/reset-password
```

**Public** - rate-limited. Resets a user's password using a reset token (generated by an admin).

**Request:**

```json
{
  "token": "hex-encoded-reset-token",
  "password": "new-password-min-8-chars"
}
```

**Response** (204): No content.

| Status | Description |
|--------|-------------|
| 404    | Token not found |
| 409    | Token already used |
| 410    | Token has expired |

### Get Current User's Project Role

```
GET /api/v1/auth/me/project-role/{key}
```

Returns the current user's effective role for a specific project.

## OIDC / Single Sign-On

### Authorize (Start SSO Flow)

```
GET /api/v1/auth/oidc/authorize
```

**Public.** Redirects the user to the configured OIDC identity provider. Sets HMAC-signed state and nonce cookies for CSRF protection.

### OIDC Callback

```
GET /api/v1/auth/oidc/callback
```

**Public** - rate-limited. Handles the OIDC provider callback. Three possible outcomes:

1. **Existing identity found** - creates a session and redirects to `/`
2. **Email matches existing user** - redirects to `/link-account` for password confirmation
3. **New user** - auto-provisions account with the configured default role and redirects to `/`

### Link OIDC Identity

```
POST /api/v1/auth/oidc/link
```

**Public** - rate-limited. Links an OIDC identity to an existing account. Requires a valid `oidc_pending` cookie (set during the callback flow) and the user's password for verification.

**Request:**

```json
{
  "password": "your-password"
}
```

**Response** (200): User object. Sets `session_id` cookie.

### Get OIDC Config

```
GET /api/v1/auth/oidc/config
```

**Permission:** `org:oidc:manage` (admin only)

Returns the current OIDC provider configuration (client secret is included for admin management).

**Response** (200) when configured:

```json
{
  "configured": true,
  "provider": {
    "id": "uuid",
    "name": "Okta",
    "issuer_url": "https://example.okta.com",
    "client_id": "...",
    "scopes": "openid email profile",
    "default_role": "member",
    "enabled": true
  }
}
```

**Response** (200) when not configured:

```json
{
  "configured": false
}
```

### Update OIDC Config

```
PUT /api/v1/auth/oidc/config
```

**Permission:** `org:oidc:manage` (admin only)

Creates or updates the OIDC provider configuration. Validates OIDC discovery before saving when `enabled` is `true`.

**Request:**

```json
{
  "name": "Okta",
  "issuer_url": "https://example.okta.com",
  "client_id": "your-client-id",
  "client_secret": "your-client-secret",
  "scopes": "openid email profile",
  "default_role": "member",
  "enabled": true
}
```

`client_secret` can be omitted on updates to keep the existing value. `scopes` defaults to `"openid email profile"` if empty. `default_role` must be `"admin"` or `"member"` (defaults to `"member"`).

**Response** (200): Provider object.

### Delete OIDC Config

```
DELETE /api/v1/auth/oidc/config
```

**Permission:** `org:oidc:manage` (admin only)

Removes the OIDC provider configuration and disables SSO.

**Response** (204): No content.

### List Linked OIDC Identities

```
GET /api/v1/auth/oidc/identities
```

Returns OIDC identities linked to the current user's account.

**Response** (200):

```json
[
  {
    "id": "uuid",
    "provider_id": "uuid",
    "subject": "google-oauth2|12345",
    "email": "user@example.com",
    "created_at": "2025-01-01T00:00:00Z"
  }
]
```

## Users (Admin Only)

All endpoints in this section require `org:users:manage` permission (admin role).

### List Users

```
GET /api/v1/management/users
```

Returns a paginated list of all users. Supports `?limit=` and `?offset=` query parameters.

**Response** (200):

```json
{
  "data": [
    {
      "id": "uuid",
      "email": "admin@example.com",
      "display_name": "Alice",
      "role": "admin",
      "created_at": "2025-01-01T00:00:00Z",
      "updated_at": "2025-01-01T00:00:00Z"
    }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```

### Invite User

```
POST /api/v1/management/users/invite
```

Creates an invite token for a new user. The token expires in 7 days.

**Request:**

```json
{
  "email": "newuser@example.com",
  "role": "member"
}
```

`role` must be `"admin"` or `"member"`. Defaults to `"member"` if omitted.

**Response** (201):

```json
{
  "id": "uuid",
  "token": "hex-encoded-token",
  "expires_at": "2025-01-08T00:00:00Z"
}
```

Share the token with the user. They accept it via `POST /api/v1/auth/accept-invite`.

### List Pending Invites

```
GET /api/v1/management/users/invites
```

Returns all pending (unaccepted) invites.

**Response** (200): Array of invite objects.

### Delete User

```
DELETE /api/v1/management/users/{id}
```

Deletes a user. You cannot delete yourself.

**Response** (200):

```json
{
  "status": "deleted"
}
```

| Status | Description |
|--------|-------------|
| 400    | Cannot delete yourself |
| 404    | User not found |

### Generate Password Reset Token

```
POST /api/v1/management/users/{id}/reset-password
```

Generates a password reset token for a user. The token expires in 24 hours.

**Response** (201):

```json
{
  "token": "hex-encoded-token",
  "expires_at": "2025-01-02T00:00:00Z"
}
```

Share the token with the user. They use it via `POST /api/v1/auth/reset-password`.

### Get User's Project Assignments

```
GET /api/v1/management/users/{id}/projects
```

Returns the project-specific role assignments for a user.

**Response** (200):

```json
[
  {
    "project_id": "uuid",
    "project_key": "my-project",
    "project_name": "My Project",
    "role": "editor"
  }
]
```

### Update User's Project Assignments

```
PUT /api/v1/management/users/{id}/projects
```

Replaces all project-specific role assignments for a user. Assignments not in the new list are removed.

**Request:**

```json
{
  "assignments": [
    { "project_id": "uuid-1", "role": "editor" },
    { "project_id": "uuid-2", "role": "viewer" }
  ]
}
```

**Response** (200): Updated array of project assignments.

## Flags

### Create Flag

```
POST /api/v1/projects/{key}/flags
```

**Permission:** `flags:write`

**Request:**

```json
{
  "key": "new-checkout-flow",
  "name": "New Checkout Flow",
  "description": "Enables the redesigned checkout experience",
  "value_type": "boolean",
  "flag_type": "release",
  "default_value": false,
  "tags": ["frontend", "checkout"],
  "owner_id": "uuid",
  "environment_overrides": {
    "development": { "enabled": true }
  }
}
```

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| `key` | Yes | | Unique identifier within the project |
| `name` | Yes | | Human-readable name |
| `description` | No | `""` | Description |
| `value_type` | No | `"boolean"` | One of: `boolean`, `string`, `number`, `json` |
| `flag_type` | No | `"release"` | One of: `release`, `experiment`, `operational`, `kill-switch`, `permission` |
| `default_value` | No | `false` | Default value matching the value type |
| `tags` | No | `[]` | Array of tag strings |
| `owner_id` | No | `null` | User ID of the flag owner |
| `environment_overrides` | No | `{}` | Per-environment enabled state overrides |

**Response** (201): Flag object.

| Status | Description |
|--------|-------------|
| 409    | Flag key already exists in this project |

### List Flags

```
GET /api/v1/projects/{key}/flags
```

**Permission:** `flags:read`

**Query parameters:**

| Parameter | Description |
|-----------|-------------|
| `tag` | Filter by tag |
| `search` | Search by key or name |
| `lifecycle_status` | Filter by lifecycle status |
| `flag_type` | Filter by flag type |
| `owner` | Filter by owner ID |
| `include` | Set to `environment_configs` to include per-env configs |
| `limit` | Pagination limit (default: 50) |
| `offset` | Pagination offset (default: 0) |

**Response** (200):

```json
{
  "data": [
    {
      "id": "uuid",
      "key": "new-checkout-flow",
      "name": "New Checkout Flow",
      "value_type": "boolean",
      "flag_type": "release",
      "tags": ["frontend"],
      "lifecycle_status": "active",
      "created_at": "2025-01-01T00:00:00Z"
    }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```

### Update Per-Environment Config

```
PUT /api/v1/projects/{key}/flags/{flag}/environments/{env}
```

**Permission:** `flags:write` (also checks environment access restrictions)

Updates the flag configuration for a specific environment, including enabled state, default variant, variants, and targeting rules.

**Request:**

```json
{
  "enabled": true,
  "default_variant": "enabled",
  "variants": [
    {
      "key": "enabled",
      "value": true,
      "weight": 100
    }
  ],
  "targeting_rules": [
    {
      "name": "Beta users",
      "percentage": 100,
      "variant": "enabled",
      "conditions": [
        {
          "attribute": "plan",
          "operator": "equals",
          "value": "pro"
        }
      ]
    }
  ]
}
```

**Response** (200): Updated environment config object.

### Promote Environment Config

```
POST /api/v1/projects/{key}/flags/{flag}/environments/{env}/promote
```

**Permission:** `flags:write` (also checks environment access restrictions)

Copies a flag's configuration (variants and targeting rules) from a source environment to the target environment. The target must come after the source in sort order (forward-only promotion). The target environment's enabled state is preserved.

**Request:**

```json
{
  "source_environment_key": "staging"
}
```

**Response** (200): Updated target environment config.

| Status | Description |
|--------|-------------|
| 400    | Target environment must come after source in sort order |

### Archive / Unarchive Flag

```
PUT /api/v1/projects/{key}/flags/{flag}/archive
```

**Permission:** `flags:write`

Archives or unarchives a flag. Archived flags return `"archived"` as the evaluation reason and pending schedules are cancelled.

**Request:**

```json
{
  "archived": true
}
```

**Response** (200): Updated flag object.

### Override Staleness Status

```
PUT /api/v1/projects/{key}/flags/{flag}/staleness
```

**Permission:** `flags:write`

Manually marks a flag as stale. Only accepts `"stale"` as the status value.

**Request:**

```json
{
  "status": "stale"
}
```

**Response** (200): Updated flag object.

### Bulk Flag Actions

```
POST /api/v1/projects/{key}/flags/bulk
```

**Permission:** `flags:write`

Performs an action on multiple flags at once (up to 200).

**Request:**

```json
{
  "action": "enable",
  "flag_keys": ["flag-1", "flag-2", "flag-3"],
  "environment_key": "production"
}
```

| Action | Required fields | Description |
|--------|----------------|-------------|
| `enable` | `environment_key` | Enable flags in the specified environment |
| `disable` | `environment_key` | Disable flags in the specified environment |
| `archive` | | Archive the flags |
| `add_tags` | `tags` | Add tags to the flags |
| `remove_tags` | `tags` | Remove tags from the flags |
| `set_owner` | `owner_id` | Set the owner for all flags (use `null` to clear) |

**Response** (200):

```json
{
  "batch_id": "uuid",
  "results": [
    { "flag_key": "flag-1", "success": true },
    { "flag_key": "flag-2", "success": true },
    { "flag_key": "flag-3", "error": "flag is archived" }
  ]
}
```

## Webhooks

Project-scoped HTTP webhooks that notify external services when management events occur. All webhook endpoints require `project:settings` permission.

### Supported Event Types

| Event | Description |
|-------|-------------|
| `flag.created` | A new flag was created |
| `flag.updated` | A flag's metadata was updated |
| `flag.deleted` | A flag was deleted |
| `flag.archived` | A flag was archived or unarchived |
| `flag_config.updated` | A flag's per-environment config was updated |
| `segment.created` | A new segment was created |
| `segment.updated` | A segment was updated |
| `segment.deleted` | A segment was deleted |
| `environment.created` | A new environment was created |
| `webhook.test` | A test delivery (sent via the test endpoint) |

### Webhook Payload Format

All webhook deliveries include the following headers:

| Header | Description |
|--------|-------------|
| `Content-Type` | `application/json` |
| `X-Togglerino-Signature` | HMAC-SHA256 hex digest of the request body using the webhook secret |
| `X-Togglerino-Event` | The event type (e.g., `flag.created`) |
| `X-Togglerino-Delivery` | Unique delivery ID |

**Payload structure:**

```json
{
  "type": "flag.created",
  "timestamp": "2026-01-01T00:00:00Z",
  "project_id": "uuid",
  "actor": {
    "id": "uuid",
    "email": "user@example.com"
  },
  "entity": { "...event-specific data..." }
}
```

### Signature Verification

To verify a webhook delivery, compute the HMAC-SHA256 of the raw request body using your webhook secret and compare it to the `X-Togglerino-Signature` header value:

```python
import hmac, hashlib

def verify(body: bytes, secret: str, signature: str) -> bool:
    expected = "sha256=" + hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
```

### Retry Behavior

Failed deliveries (non-2xx status or network error) are retried up to **3 times** with exponential backoff. Delivery logs are retained for **30 days** and automatically cleaned up.
